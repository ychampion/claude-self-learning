# /list-skills Command

Show all skills generated by the self-learning plugin.

## Usage

```
/list-skills              # Show all skills from all locations
/list-skills --global     # Only ~/.claude/skills
/list-skills --local      # Only ./.claude/skills
/list-skills --plugin     # Only <plugin-path>/storage/skills
```

## Process

### Step 1: Scan Skill Locations

Search for skills in these directories:

1. **Global**: `~/.claude/skills/*/SKILL.md`
2. **Local**: `./.claude/skills/*/SKILL.md`
3. **Plugin storage**: `<plugin-path>/storage/skills/*/SKILL.md`

For each skill found, read the frontmatter and `.meta.json` if available.

### Step 2: Display Table

```

├──────────────────┬─────────┬──────────────┬─────────────┬───────────────────┤

├──────────────────┼─────────┼──────────────┼─────────────┼───────────────────┤

│ prisma-orm       │ 1.1.0   │ 2024-03-01   │ plugin      │ 2024-03-01        │
└──────────────────┴─────────┴──────────────┴─────────────┴───────────────────┘

Total: 3 skills
```

### Step 3: Show Outdated Warning

For skills where sources were verified > 30 days ago:

```
⚠️  The following skills may be outdated:
   - prisma-orm (verified 45 days ago)

Use `/update-skill <topic>` to refresh with latest information.
```

## Additional Information

For each skill, also track:
- Number of sources used
- Primary language focus (Python, TypeScript, etc.)
- Size (token estimate)

If user requests more info on a specific skill:


## Implementation

```bash
# Find all SKILL.md files
find ~/.claude/skills -name "SKILL.md" 2>/dev/null
find ./.claude/skills -name "SKILL.md" 2>/dev/null
find <plugin-path>/storage/skills -name "SKILL.md" 2>/dev/null
```

For each found skill:
1. Read frontmatter for name, version, sources_verified
2. Read .meta.json for created, updated dates
3. Calculate days since verification
4. Format and display
